Title: Privileged / Production Access Request Procedure
Department: Access Management
Document Type: Procedure
Purpose: Define the approval process for granting privileged, administrator, or production system access.
Applicable Issues: Need administrator access, requesting production server access, privileged access request, elevated permissions needed, admin rights on system.

Symptoms:
- Employee or team requires elevated permissions to perform a specific job function
- Employee requests administrator rights on their laptop or a specific application
- Team requests production database or server access for a project

Troubleshooting / Procedure:
1. Employee submits a Privileged Access Request through the Employee Portal, specifying the system, scope of access, and business justification.
2. The request is routed to the appropriate system owner for review.
3. A security reviewer independently evaluates the request against least-privilege principles.
4. Production administrator access requires authorization from both the appropriate system owner and the security reviewer before it is granted.
5. Approved access is provisioned with an expiration date where applicable, and is logged for audit purposes.
6. Employee is notified once access has been granted, along with any usage conditions.

Expected Result: Access is granted only after documented approval from the required approvers, with an audit trail in place.

Escalation Criteria: Escalate to Access Management leadership if a request is urgent (e.g., production incident) and requires expedited review; expedited requests still require documented approval, just on a shortened timeline.

Important Notes: This document describes the approval process only. There is no process for bypassing system owner or security reviewer approval under any circumstance, including urgency claims.

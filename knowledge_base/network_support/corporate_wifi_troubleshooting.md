Title: Corporate Wi-Fi Troubleshooting
Department: Network Support
Document Type: Troubleshooting Guide
Purpose: Help employees resolve issues connecting to or staying connected on the TCS Enterprise office Wi-Fi network.
Applicable Issues: Can't connect to office Wi-Fi, Wi-Fi keeps dropping, weak Wi-Fi signal in office, Wi-Fi password not accepted, no internet on office network.

Symptoms:
- Laptop cannot find or connect to the corporate Wi-Fi network
- Wi-Fi connects but shows "no internet access"
- Wi-Fi signal repeatedly drops in certain areas of the office
- Employee is prompted for network credentials repeatedly

Troubleshooting / Procedure:
1. Confirm Wi-Fi is enabled on the laptop and airplane mode is off.
2. Forget the corporate Wi-Fi network on the device and reconnect using current network credentials.
3. Move closer to a Wi-Fi access point to rule out a weak signal area.
4. Restart the laptop's network adapter (disable/enable) or restart the laptop entirely.
5. Confirm other employees in the same area are experiencing the same issue, which may indicate a localized access point outage.
6. If the issue is isolated to one device, check for outdated network drivers.

Expected Result: Laptop connects reliably to corporate Wi-Fi with stable internet access.

Escalation Criteria: Escalate to Network Support if multiple employees in the same area report simultaneous Wi-Fi issues, or if the problem persists after reconnecting and restarting the network adapter.

Important Notes: This document covers office Wi-Fi connectivity only, not VPN remote access issues (see VPN Troubleshooting Guide).

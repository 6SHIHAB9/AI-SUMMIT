Title: Laptop Performance Troubleshooting
Department: IT Support
Document Type: Troubleshooting Guide
Purpose: Help employees and support agents diagnose and resolve slow or unresponsive company laptops.
Applicable Issues: Laptop running slow, laptop freezing, high CPU usage, laptop overheating during normal use, applications taking a long time to open, laptop lagging after Windows updates.

Symptoms:
- Laptop takes several minutes to boot or wake from sleep
- Applications such as Outlook, Teams, or the browser are slow to respond
- Fan runs constantly under light workloads
- Laptop feels sluggish after a recent Windows update
- Multiple applications open at once cause the system to freeze

Troubleshooting / Procedure:
1. Restart the laptop fully (not sleep/hibernate) and confirm whether performance improves.
2. Check Task Manager for processes consuming unusually high CPU, memory, or disk usage.
3. Confirm available free disk space is at least 15% of total capacity; if not, guide the employee through clearing temporary files and browser cache.
4. Verify that Windows Updates have finished installing in the background (a pending update can cause temporary slowdowns).
5. Confirm the corporate antivirus/endpoint protection is not mid-scan, as full scans can temporarily reduce performance.
6. Close unnecessary startup applications using Task Manager > Startup tab.
7. If the laptop is more than 3 years old and performance issues persist after the above steps, flag for a hardware refresh evaluation.

Expected Result: Laptop returns to normal responsiveness after cleanup, update completion, or startup optimization.

Escalation Criteria: Escalate to IT Support hardware team if performance issues persist after all steps above, or if Task Manager shows abnormal disk/CPU usage that cannot be traced to a known application.

Important Notes: This document covers general slowness and responsiveness issues only. It does not cover physical hardware failure (see Hardware Failure Procedure) or software installation issues (see Software Installation Guide).

Title: Microsoft Office Troubleshooting
Department: Software Support
Document Type: Troubleshooting Guide
Purpose: Help resolve common issues with Microsoft Office applications (Word, Excel, Outlook, Teams) used at TCS Enterprise.
Applicable Issues: Outlook not sending or receiving email, Word document won't open, Excel crashing, Teams not loading, Office activation error, Office application freezing.

Symptoms:
- Outlook shows a "disconnected" or "trying to connect" status and email does not sync
- Word or Excel crashes when opening certain files
- Teams fails to load or gets stuck on a loading screen
- Office application prompts for activation or shows a licensing error

Troubleshooting / Procedure:
1. Restart the affected Office application, and if that fails, restart the laptop.
2. For Outlook connectivity issues, confirm the laptop has internet access and that the employee's account credentials are valid (see Password Reset Procedure if login is failing).
3. For file-opening crashes, try opening the file in Safe Mode (hold Ctrl while launching the app) to rule out a corrupted add-in.
4. For licensing/activation errors, confirm the employee's account is properly licensed by checking the Employee Portal software entitlements page.
5. Clear the Teams cache (%appdata%\Microsoft\Teams) and restart the application if Teams fails to load.
6. If issues persist, run the built-in Office repair tool via Control Panel > Programs > Microsoft Office > Change > Quick Repair.

Expected Result: Office applications function normally with email sync, file access, and Teams connectivity restored.

Escalation Criteria: Escalate to Software Support if the Office repair tool does not resolve the issue, or if licensing shows the employee is missing an entitlement they should have.

Important Notes: This document covers Microsoft Office application issues only. General laptop performance issues unrelated to Office are covered in Laptop Performance Troubleshooting.

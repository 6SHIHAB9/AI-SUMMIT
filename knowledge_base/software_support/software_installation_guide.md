Title: Software Installation Guide
Department: Software Support
Document Type: Guide
Purpose: Explain how employees can request and install approved software through the Internal Software Center.
Applicable Issues: Need to install software, software not found in Software Center, requesting a new application, can't install approved application, software installation stuck.

Symptoms:
- Employee cannot find the application they need in the Internal Software Center
- Software installation from the Internal Software Center fails or hangs
- Employee needs an application not currently on the approved list

Troubleshooting / Procedure:
1. Direct the employee to the Internal Software Center application on their laptop and search for the required software.
2. If listed, the employee selects "Install" and the software deploys automatically; installation typically completes within 15-30 minutes.
3. If installation hangs or fails, restart the Internal Software Center client and retry.
4. Confirm the laptop has sufficient free disk space for the installation.
5. If the software is not listed in the Internal Software Center, the employee must submit a New Software Request through the Employee Portal, including business justification.
6. New software requests are reviewed by Software Support for licensing and security compliance before approval and addition to the catalog.

Expected Result: Approved software installs successfully and is available for use.

Escalation Criteria: Escalate to Software Support if an installation repeatedly fails after retrying, or if a new software request needs expedited review for a business-critical need.

Important Notes: Employees must not install unapproved software from outside the Internal Software Center. This document does not cover troubleshooting of a specific installed application's functionality (see Microsoft Office Troubleshooting for Office-specific issues).

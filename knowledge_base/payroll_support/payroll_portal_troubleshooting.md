Title: Payroll Portal Troubleshooting
Department: Payroll Support
Document Type: Troubleshooting Guide
Purpose: Help resolve access and display issues with the TCS Enterprise Payroll Portal.
Applicable Issues: Can't log into Payroll Portal, Payroll Portal showing an error, salary details not loading, Payroll Portal access request.

Symptoms:
- Employee cannot log into the Payroll Portal
- Payroll Portal loads but salary or deduction details do not display
- Employee sees an error message when trying to view payroll history

Troubleshooting / Procedure:
1. Confirm the employee is using the same company credentials used for the Employee Portal; the Payroll Portal uses single sign-on.
2. If login fails, determine whether it is a password issue (see Password Reset Procedure) or account lockout (see Account Lockout Troubleshooting).
3. If logged in but data does not display, ask the employee to clear browser cache or try a different supported browser.
4. Confirm the employee's payroll record is active in the system; new hires may need up to 48 hours after start date for payroll records to populate.
5. If salary details appear incorrect (not just missing), this is a data issue and must be forwarded to Payroll Support directly rather than treated as a portal access issue.

Expected Result: Employee can log into the Payroll Portal and view their payroll information correctly.

Escalation Criteria: Escalate to Payroll Support for any suspected incorrect salary, deduction, or tax data. Escalate to Access Management if login continues to fail after password and lockout checks are ruled out.

Important Notes: This document covers portal access and display issues only, not disputes over pay amounts, which must go to Payroll Support directly. See Payslip Access FAQ for payslip-specific questions.
